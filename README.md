# 小八记账 🧾

一个为初中生（以及所有人）设计的 **iOS 记账 App**：把微信 / 支付宝的账单截图通过**快捷指令**发给它，它就能自动识别**金额**和**消费时间**，运行时询问分类和备注，保存截图缩略图，并在主页顶部显示**本周消费**汇总。**全程零联网**：OCR 在本地运行，不请求任何网络权限。

> 名字来源：项目文件夹 `xbjz` 原为"小本记账"拼音缩写，App 现定名 **小八记账**（代码内部标识沿用 XiaoBenJiZhang，不影响使用）。

---

## 一、它能做什么（功能清单）

| 功能 | 怎么用 | 说明 |
|------|--------|------|
| 📸 小票识别记账 | 快捷指令传入截图（或在 App 内选图） | 自动 OCR 识别金额和时间并保存缩略图；金额识别不到会要求手动输入，分类一律手动选 |
| 📊 周消费汇总 | 打开 App 即可看到 | 顶部玻璃卡片：总金额、笔数、和前一周对比、各分类消费（无比例数字）；**左右滑动查看上一周 / 下一周**；**点击分类弹出 App Store 式半屏明细**（下滑即关闭） |
| 📤 导出本周账单 | 主页右上角分享按钮 | 生成 CSV（Excel/Numbers 可打开，中文不乱码），可存储到"文件"或分享给微信等 |
| 📋 账单明细 | 主页下方列表 | 按天分组显示全部记录；**长按条目批量选择删除**，左滑单条删除；条目显示分类 emoji，不显示截图 |
| ✍️ 手动记一笔 | 主页右上角「+」 | 分类**默认选中餐饮**；**拍小票识别按钮在金额输入框右侧** |
| 🔍 查看与修改 | 点击任意一条账单 | 可修改金额/分类/时间/备注，可放大看截图，可删除 |
| 🗑️ 左滑删除 | 列表里左滑任意一条 | 快速删掉记错的账单 |

## 二、快捷指令入口（App Intent）

App 对快捷指令暴露了一个动作，**无需任何额外配置**，装好 App 后打开「快捷指令」App 就能搜到它。

### 动作：识别小票并记账

| 项目 | 说明 |
|------|------|
| 用途 | 传入一张消费截图 → 识别金额时间（**识别不到金额会弹窗要求输入**）→ **手动选分类** → 询问备注 → 存入账本 |
| 参数 1 | **消费截图**（图片文件，支持 PNG / JPEG 等常见格式） |
| 参数 2 | **分类**（餐饮 / 交通 / 娱乐 / 其他；提前选了直接用，没选运行时弹列表选，**不做自动识别**） |
| 参数 3 | **金额**（可选预设；OCR 识别失败时使用，没填会弹窗要求输入） |
| 参数 4 | **备注**（可提前填；没填的话运行时询问，没有备注填「无」） |
| 返回值（成功） | 提示气泡，例如：`记账成功！🍜 餐饮 ¥25.50（和同学吃麻辣烫）` |
| 返回值（失败） | 错误提示，例如：`金额不太对，请打开小八记账 App 手动记这一笔` |

配置步骤见 [使用指南.md](./使用指南.md)（含把截图"分享"给快捷指令的方法）。

## 三、识别规则说明（OCR）

识别全部在**手机本地**完成（使用 Apple 的 Vision 文字识别框架），**不上传任何数据到网络**，保护隐私。

1. **金额**：按优先级匹配文字——
   ① 关键词（实付 / 合计 / 总计 / 小计 / 应付 / 付款 / 收款 / 金额 / 支付…）后面的数字，取最后一条；**关键词后跟「时间 / 日期 / 单号 / 订单 / 方式」等标签的直接排除**（防止把 `付款时间 2026-10-24` 里的 2026 当成金额）；
   ② 找不到再取 `¥ ￥ $` 符号后面的**最大**数字；
   ③ 再找 `xx.xx 元` 形式的最大数字；
   ④ **兜底**：孤立的两位小数数字（截图裁剪后只剩"大字金额"的情况），取最大；
   ⑤ 全角字符自动转半角（`１２８．００` → `128.00`）；超过 1 千万的数字、以及 4 位年份后紧跟 `年 - . /` 的数字都会被丢弃（防止订单号 / 日期混进来）。
2. **消费时间**：**优先在包含「时间 / 日期」字样的行里找**（最可靠，不会被订单号干扰），找不到再全文搜索；识别 `2026-10-24 12:30`、`2026/10/24`、`2026.10.24 20:15:33`、`2026年10月24日 12时30分`、`10-24 20:15`（自动补今年，比现在晚就按去年算）等格式；只识别到日期没时间时，用当天当前时间；完全识别不到就用"现在"。
3. **分类**：固定 4 类（餐饮 / 交通 / 娱乐 / 其他），**全部由用户手动选择**，不识别商家、不自动猜分类。历史数据里的自定义分类文字仍能正常显示。
4. **零联网**：OCR 的语言修正功能（可能触发系统按需下载语言模型）已关闭，App 不发起任何网络请求。唯一的例外是系统相册：如果选的照片只存在 iCloud 上，系统会先把它下载到本地（下载的是你自己的照片）。
5. 识别结果只是"建议"，记账前都可以在 App 里修改。
6. 解析算法在 `tools/test_parser.py` 里有 10 组真实场景的回归测试（微信/支付宝/裁剪截图/全角字符等），改规则时先跑测试再改代码。

## 四、数据存在哪里？会丢吗？

- 所有账单存在手机本地的 **SwiftData 数据库**（可以理解为 App 自带的一个小账本文件）。
- 缩略图以"外部存储"方式保存（数据库里只放一个指针，图片单独存文件），账单多了也不会把数据库撑慢。
- 卸载 App 会删除数据；换新 iPhone 时用电脑备份恢复即可带走数据。

## 五、技术架构（给想深入学习的你）

| 技术 | 用在哪 |
|------|--------|
| Swift 5.9 + SwiftUI | 全部界面，iOS 26.0+ |
| 液态玻璃（Liquid Glass） | iOS 26 全新设计语言：本周卡片 `glassEffect` 染色玻璃、分类方块 `GlassEffectContainer`、保存按钮 `glassProminent`（iOS 27 同样适用） |
| Design Tokens（视觉对齐） | 全部页面统一圆角 / 间距 / 颜色（`DesignTokens.swift`），主题色 #43B6E4，保证视觉对齐 |
| SwiftData | 本地数据存储（`ExpenseRecord` 模型） |
| Vision（VNRecognizeTextRequest） | 截图文字识别（中文简繁 + 英文，精准模式） |
| App Intents | 快捷指令动作 `识别小票并记账` |
| Combine | 输入金额时的自动清洗（防抖 0.3 秒） |
| ImageIO | 高效生成缩略图（不解码整张大图，省内存） |
| XcodeGen + GitHub Actions | `project.yml` 一键生成工程；云端自动构建 |

### 模块 API 速查表

| 模块 | 参数 | 返回值 |
|------|------|--------|
| `ReceiptScanner.scan(imageData:)` | 图片二进制 `Data` | `ReceiptInfo`（金额 `Double?`、时间 `Date?`、分类、识别原文） |
| `ThumbnailGenerator.thumbnail(from:maxPixel:)` | 图片 `Data`、最长边像素（默认 400） | 压缩后的 JPEG `Data?` |

## 六、开发环境要求

- 一台 Mac 电脑 + Xcode 26 及以上（免费，App Store 下载）
- 运行的 iPhone 需 iOS 26 及以上（iOS 27 也可以）；模拟器也可以
- 用 XcodeGen 一键生成工程：Mac 上执行 `brew install xcodegen`，然后在项目目录执行 `xcodegen generate`
- 具体安装步骤见 [使用指南.md](./使用指南.md)

## 七、云端构建（GitHub Actions）

[![Build](https://github.com/yddxyi/xiaobenjizhang/actions/workflows/build.yml/badge.svg)](https://github.com/yddxyi/xiaobenjizhang/actions/workflows/build.yml)

每次 push 代码到 GitHub，云端 Mac 会自动完成：

**Build（验证编译）**
1. 安装 XcodeGen 并从 `project.yml` 生成 Xcode 工程
2. 用 Xcode 26 / iOS 26 SDK 编译 App（液态玻璃代码在这里验证能否编译通过）
3. 把编译好的模拟器版 `.app` 打包成构建产物（Artifacts），可在 Actions 页面下载

**Build IPA（真机安装包，供 p12 自签）**
1. 编译**真机版（arm64）Release** 包
2. 打包成**未签名 IPA**（`XiaoBenJiZhang-unsigned-ipa`）
3. 下载后用爱思助手 / Sideloadly 配合自己的 **p12 + 描述文件**签名安装（无 Mac 方案，步骤见 [使用指南.md](./使用指南.md)）

**本地一行命令触发**：push 之后到仓库的 **Actions** 标签页看进度；绿色 ✓ = 构建成功，红色 ✗ 点进去能看到报错。

## 八、已知限制 & 后续优化方向

**当前限制**
- 识别依赖截图清晰度：模糊、裁剪掉金额行的截图可能识别不到金额（此时 App 会提示手动记账）。
- 金额识别只支持人民币为主的常见格式（¥ / 元）。
- 只记支出，暂时没有"收入"。

**以后可以加的功能（欢迎提需求）**
1. 📈 月度统计图表 + 分类占比饼图
2. 💰 每月预算和超支提醒（本地通知）
3. 📤 导出 CSV / Excel 给爸妈看账
4. ☁️ iCloud 同步，换设备不丢账
5. 📱 桌面小组件：一睁眼就看到本周花了多少
6. 🤖 用 Core ML 训练"账单分类模型"，让分类猜得更准
7. 🧮 支持收入 / 转账类型
